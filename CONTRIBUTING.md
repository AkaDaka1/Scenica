# Как помочь проекту

Спасибо за интерес к Scenica. Проект небольшой и поддерживается в свободном
режиме, поэтому любые аккуратные правки приветствуются.

## Перед началом

1. Убедитесь, что в проекте нет открытого issue или pull request по той же теме.
2. Для крупных изменений сначала опишите идею в issue, чтобы согласовать подход.

## Локальная настройка

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
cp .env.example .env
```

Для запуска тестов нужны `requests`, `bcrypt` и `python-jose` — они уже в
`requirements.txt`.

## Стиль изменений

- Придерживайтесь структуры и стиля окружающего кода.
- Конфигурация читается из переменных окружения; не добавляйте в код реальные
  секреты и значения по умолчанию, похожие на секреты.
- Новые эндпоинты API сопровождайте схемами Pydantic и обрабатывайте ошибки так
  же, как соседние эндпоинты.
- Обновляйте документацию в `docs/`, если меняется поведение или эндпоинты.

## Тесты

Перед отправкой pull request выполните:

```bash
python -m pytest
```

Если добавили функциональность, постарайтесь покрыть её тестами.

## Коммиты и pull request

- Делайте небольшие осмысленные коммиты с понятным описанием.
- В pull request кратко опишите, что изменено и как это проверить.
- Не включайте в коммиты файлы `.env`, локальные базы, артефакты сборки и логи.
