# Руководство пользователя (десктопный клиент Scenica)

## Запуск

1. Запустите API (`python start_api.py` или `docker compose up`).
2. Запустите клиент: `python start_app.py`.
3. Войдите под учётной записью сотрудника.

## Режимы работы

### Просмотр справочников

В верхней части окна находится **выбор справочника: от таблицы**. Слева
отображается таблица с прокси-моделью (поиск и сортировка), справа — панель
действий.

### Фильтрация

В поле над таблицей вводится текст — строки фильтруются по всем колонкам.

### Добавление

**Панель действий: добавление** открывает форму **«Добавить»** для текущего
справочника с полями, подсказками и выпадающими списками.

### Редактирование

**Панель действий: обновление** отправляет изменения выделенной строки на
API. Недоступные при роли поля редактировать нельзя.

### Удаление

**Панель действий: удаление** удаляет выделенную строку в текущем справочнике.

### Дашборд

В режиме панели отображается сводная информация; дополнительные действия
выполняются кнопками на панели инструментов.

### Файл ТЗ сценария (n8n)

1. Откройте справочник **сценарии**.
2. Выберите строку сценария.
3. Пользуйтесь кнопками **загрузки файла ТЗ**, **скачивания** и
   **«Отправить в n8n»** на панели инструментов.

Если в поле особого указания клиент выдаёт ошибку — отправьте `SCENARIO_TZ_UPLOAD_ROOT`
или проверьте, что обработка включена на стороне n8n. Успешная обработка
появляется в отдельном поле результата, ошибка — во всплывающем сообщении.

## Логи приложения

Файл логов в Windows:

`%LOCALAPPDATA%\Scenica\logs\client.log`

Логи создаются относительно места запуска (они не коммитятся).
